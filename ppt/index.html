Pipeline · How It Works

A two-stage cascade.

The system mimics how an inspector would read a photo — first scan broadly, then verify each candidate.

End-to-end flow
01
Photo input
A single street-view image enters the screening queue.
02 · CLIP
Broad screening
The retriever keeps the top-5 most plausible violation categories.
03 · Gemma
Binary verification
Each candidate gets a yes/no verdict, confidence, and short rationale.
04
Inspector-ready flags
The final output is a structured 9-category vector for review.
Design principle — CLIP for recall, Gemma for precision. CLIP casts a wide net; Gemma rejects wrong candidates before a flag reaches the inspector queue.

What The Model Sees

Violations are visual, not abstract.

The strongest categories have concrete visual anchors: a vehicle that appears abandoned, visible graffiti, and vegetation that clearly exceeds normal maintenance.

This is why agreement matters: clear visual definitions create clear model behavior. Ambiguous labels create ambiguous outputs.

Methodology · Insight
06 / 14
Why Bucket By Agreement

When humans cannot agree, AI also struggles.

We discovered a clean correlation: AI accuracy tracks inter-rater agreement category by category. The bottleneck isn't the algorithm — it's label definition. So we report results stratified by how well our three human annotators agreed.

Three Modes

How to use the system.

Different categories slot into different operating modes — the deployment isn't all-or-nothing.

Full automation
4 categories

Almost-perfect & Substantial tiers. AI generates a violation-notice draft directly into the inspector follow-up queue. No pre-screening required.

Graffiti · Vehicles · Vegetation · Roof

AI-assisted
4 categories

Moderate & Fair tiers. AI flags go into a high-priority queue; inspector still spot-checks unflagged photos because recall is conservative.

Windows · Junk · Paint

Hold
1 category

Slight tier. Keep the existing manual workflow until the city provides a clearer SOP for what counts as a violation from a street-view photo.

Deteriorating chimney

Operational metrics to monitor
Weekly
Spot-check 5–10 outputs
Track whether precision is drifting on the automation tier.
Monthly

If a category's override rate spikes, the prompt or the data has shifted.
Quarterly
Re-run clean-house battery

Roadmap · Scaling
12 / 14
Adding A New Category

A repeatable onboarding flow.

When the city introduces a new violation type, this is how we decide which tier it joins.

Six-step decision flow
01
Collect samples
≥30 positives + ≥20 negatives. Write a plain-English description of the violation.
02
Three-rater pilot
Three inspectors independently label all positives. Compute Cohen's κ.
03 · κ-gate
Decide the tier
κ ≥ 0.61 → automation. 0.41–0.60 → AI-assisted. < 0.40 → fix the SOP first.
04
Write the prompt
Visual not legal · include edge cases · one sentence ≤ 25 words.
05
Integrate & test
Add to CLIP class list. Run on the 30 + 20 test set. Measure F1 and FPR.
06
Deploy decision
F1 ≥ 0.80 & FPR ≤ 5 % → automation. F1 0.50–0.80 → assisted. Else → revise SOP.
The κ test in step 02 is the most important step. If three inspectors can't agree, no model — ours or anyone else's — will perform well. Fix the labelling guidance first, then train.

Future Work · What's Next
13 / 14
Two Tracks Ahead

What we'd ask for, what we can build.

Accuracy gains depend on the city; usability gains depend on us. Both tracks in priority order.

From the client

Inputs only Riverdale Park can provide.

  1. 50–100 real clean-house photos from city records — to validate the 0 % false-alarm rate against real-world variance.
  2. Code-enforcement SOP for ambiguous categories — chimney and peeling paint definitions, plus reference photos for borderline cases.
  3. Multi-angle photos per address — improves recall on detail-heavy categories like broken windows.
  4. Severity grading — minor vs. major peeling paint, etc., so AI output maps onto actionable enforcement levels.
From our team

What we can ship next.

  1. REST API + simple web UI — inspectors upload a photo, see verdict plus confidence, one-click confirm or override.
  2. Active-learning loop — inspector overrides feed back into the prompt-tuning data set automatically.
  3. Self-service onboarding tool — a Jupyter notebook that runs the κ test and prompt template for any new category.
  4. Explainability dashboard — image regions plus model rationale per flag, so review is fast and defensible.
